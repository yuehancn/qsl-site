集群慢不一定是卡不够：三种慢，只有一种值得花钱

集群慢不一定是卡不够 —— 「慢」有三种，只有一种值得花钱。显存接近 0 是显卡压根没参与计算（配置问题，加卡一分钱作用没有）；只有第一轮慢是预热，属正常开销；并发上去了单请求反而更慢，说明撞的是通信墙（加卡会更糟）。

这个站不做什么

  • 不转载别人的评测。没有我自己机器上的原始数据，就不写。
  • 不给「大概」「应该」这类估算值。查不到就写未采集。
  • 不推荐购买渠道。我只回答「这张卡够不够」，不回答「去哪买最便宜」。

本站数字均为真机实测，逐条标注验证等级（L1 多次复测取中位 / L0 单次测量）。查不到的写「未采集」，不估算。
