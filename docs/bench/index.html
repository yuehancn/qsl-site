怎么读这张表

  • L1 = 多次测量取中位并记录波动区间，可直接用于决策。
  • L0 = 单次测量。方向可信，换版本或驱动可能偏 10% 以上。
  • 显存类数值是峰值，不是平均值 —— 选卡要按峰值卡余量。
  • 同一任务同机器只出现一条时，说明尚未复测，参考价值低于标 L1 的。

本站数字均为真机实测，逐条标注验证等级（L1 多次复测取中位 / L0 单次测量）。查不到的写「未采集」，不估算。
