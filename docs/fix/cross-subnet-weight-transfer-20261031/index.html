搬 TB 级模型权重，跨网段比同网段多等 44 小时，而且只能单向推

性能 · 1.06 TB / 54 分片L0整理于 2026-10-31 有效期 permanent

同一份 1.06 TB 权重，按实测带宽：跨网段（走 VPN 隧道）6.4 MB/s 要 46.0 小时，同网段千兆 118.2 MB/s 只要 2.49 小时，目标机本机盘 8.9 GB/s 仅 119 秒。跨网段比同网段多等 43.5 小时。更麻烦的是方向：8 段→11 段实测 100% packet loss，只能把东西推进去、拉不出来，「先传 NAS 再拷」这类绕行方案在单向拓扑下不成立。按每月搬一次算，一年白等 552 小时 = 23 天机器闲置。

模型搬运跨网段带宽单向可达VPN权重下载本地部署时间成本网络拓扑

这条适用于

  • 两台分属不同网段的机器，SSH 免密已通
  • 跨网段若经 VPN，需先确认隧道已建立

版本指纹

跨网段 6.4 MB/s / 同网段 118.2 MB/s / 本机盘 8.9 GB/s（2026-10-31 实测）

具体做法

实测环境：本机（11 段）↔ 源机（8 段，经 VPN 隧道互通）。

【跨网段吞吐（64 MiB 实测）】
dd if=/dev/zero bs=1M count=64 → 67108864 bytes (67 MB, 64 MiB) copied, 10.4592 s, 6.4 MB/s
【三档对照】
· 跨网段 VPN：6.4 MB/s（53 Mbps）
· 同网段千兆 LAN：118.2 MB/s（952 Mbps）
· 源机本机 NVMe 顺序读（oflag=direct）：8.9 GB/s
同网段 / 跨网段 = 19.06 倍（第 0 环 118.2 vs 6.2 同量级复核）。
【1.06 TB 权重换算（1,060,554,587,912 B，54 分片）】
· @6.4 MB/s → 165,719.6 s = 46.03 小时
· @118.2 MB/s → 8,973.0 s = 2.49 小时
· @8.9 GB/s → 119.2 s
跨网段比同网段多等 43.5 小时。

【单向可达实测】源机 → 11 段全线 100% packet loss（11 段内的 5 类目标：无显示机器、内容机、集群节点、网关、NAS 全不通）；11 段 → 8 段可进。

【年度推算】每月搬一次 → 46.03 × 12 = 552 小时/年 = 23 天；按机器月折旧 1,000 元、月 720 小时折算，552 小时闲置 = 767 元/年。

其他：源机另有 两条 IB/RoCE 高速口 两条 IB/RoCE 高速口存在但未纳入测试。

失效边界
① 46 小时是按实测 6.4 MB/s 对官方权重的换算，（1.06 TB 全程搬需 46 小时且占上千 GB 磁盘，未执行）。② 跨网段单向不通的成因未定位（未查网关策略/防火墙），只陈述实测现象。③ 带宽随链路负载波动，6.4 与第 0 环 6.2 同量级但非恒定值。
