四张 5060Ti 产能不如一张 5090D：别用「卡数」算产能，用「显存冗余」算

成本账 · 4 步 / 3 分钟L0整理于 2026-10-03 有效期 180d

四张同型号卡不等于四倍产能。可并行的只有采样，模型加载/VAE 解码/写盘/人看图全部串行；16GB 单卡装下 SDXL 后只剩几百 MB 余量，batch 根本铺不开。四张 5060Ti 按实际可交付图量折算约等于 0.65 张 5090D——价格是它的 0.8 倍，产能只有 0.65 倍。

显卡选型显存ComfyUISDXL硬件实测产能估算

这条适用于

  • 多卡异构（如 4×5060Ti 与 1×5090D 混用）
  • 比较的是「可交付图量」而不是理论算力

版本指纹

SDXL base 1.0 / 20 步 / CFG 7.0；2026-09-26 本机基线

具体做法

【并行 ≠ 除法】
可并行：采样
不可并行：模型加载、VAE 解码、写盘、人看图判断
→ 四张卡同接四张图，只有采样接近 1/4，其余全串行

【实测对照】SDXL 1024×1024
RTX 5090D 32GB：单张 4.98s ｜ batch4 均摊 4.17s（收益 3.89×）
RTX 5060Ti 16GB：单张 16.68s ｜ batch4 均摊 16.25s（收益仅 16%）
→ 差在显存冗余：32GB 铺得开，16GB 不敢铺

【折算】
按「单张速度×卡数」：四张 5060Ti ≈ 0.95 张 5090D
按「实际可交付图量」：四张 5060Ti ≈ 0.65 张 5090D
而四张 5060Ti 价格 ≈ 5090D 的 0.8 倍

【小卡的正确用法】
- 一张跑低价值批量试稿（换 seed 刷构图，跑废不心疼）
- 一张挂轻量常驻服务（小模型问答 / 字幕识别）
- 一张做污染性实验（装乱七八糟依赖，坏了直接重装）
只有第一张在出可交付的图。

失效边界
「0.65 张 5090D」是按实际可交付图量折算的估算值，非精确测量，随工作流与批量策略变化。数字基于 SDXL base 1.0 / 20 步 / CFG 7.0 的本机实测（2026-09-26 基线），其他模型/参数下比例会不同。
