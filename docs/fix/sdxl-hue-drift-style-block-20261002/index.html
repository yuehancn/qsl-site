SDXL 批量出图跑色：加一段风格块把色相漂移压掉四成

产出质量 · 4 步 / 10 分钟未标注整理于 2026-10-02 有效期 180d

同一提示词只换 seed，SDXL 出的 8 张图跨了 4 个色系（青绿山水/红枫版画/暖米复古/宣纸留白），跨图色相极差 80.35°、圆标准差 23.36°。根因不是模型不稳定，是提示词只写了"平涂/海报风"却没写用什么颜色 —— 模型在没被约束的维度上每次重新抽签。修法：每条提示词开头逐字粘同一段风格块（含锁定色盘），尾部补一条硬命令，负面词扩一轮。实测色相漂移降 41.4%，单张耗时只涨 1.0%。

这条适用于

  • 用 SDXL base 1.0 批量出图（同提示词只换 seed）
  • 关注的是跨图色相一致性，不是单张观感

版本指纹

ComfyUI 0.33.0 / torch 2.11.0+cu128 / SDXL base 1.0 / 1024×1024 / 20 步 / CFG 7.0 / euler+normal

具体做法

原提示词（A 组·裸）：a chinese landscape painting, mountain and pine trees, flat color, poster style
负面词：text, watermark, blurry, low quality
→ 8 张色相均值（度）：122.6 / 69.61 / 69.51 / 98.39 / 42.26 / 67.62 / 66.51 / 94.54（绿→黄绿→黄→橙黄，极差 80.35°）

修好后（B 组·风格锁定）：
开头粘：[STYLE] flat 2D vector illustration, pure flat color fill, minimal geometric shapes, poster art, limited palette: navy blue, vermilion red, cream white, charcoal black. [END STYLE]
尾部加：必须纯2D平涂！绝对不要阴影、不要渐变、不要3D体积感！必须大面积留白！
负面词追加：photorealistic, skin texture, 3d render, volumetric lighting, gradient, soft glow, bloom, airbrush, shading, shadows, warm tones, amber, sepia
→ 8 张色相均值全部落在 225–270°（蓝→紫蓝，海军蓝主导）

失效边界
① 风格块锁的是色相，锁不住面积 —— 实测饱和度离散反而升高 20.7%、亮度极差涨 179%，因为色盘里的颜色名是枚举不是配比，模型不知道"朱红只能占 5%"。要更严须再补一层面积约束或上 LoRA/IPAdapter。
② 固定 seed 只能保证同一次生成一致，管不了跨批次一致 —— 跨批次稳靠的是逐字复制的风格块。
③ 以上为 SDXL base 1.0 单机单模型实测，换模型/换采样器/换分辨率须重测。
④ 数据仅 8 张/组，样本量小，结论方向可信、精确数值仅供参考。
