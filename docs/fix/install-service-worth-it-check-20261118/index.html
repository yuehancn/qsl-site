具体做法

报价本身说明了什么

2026-11-18 采集的闲鱼数据：代部署 / 代调优服务 5 个关键词、49 条有效挂单，报价中位 ¥38。

按 100 元/小时的时薪折算，38 元 = 23 分钟；按 200 元，= 11.4 分钟。

也就是说，接单的人默认自己能在 20 分钟内，把一台完全陌生的机器上的本地模型装到「能跑」。

为什么这个假设站不住

把一台机器装到「能跑且知道自己能跑多快」，实际耗时分几块：

- 下载 llama.cpp 二进制约 1 分钟（19MB）
- 传 1.1GB 模型过内网约 1 分钟
- 1.5B 与 7B 各跑 6 档线程梯度、每档两轮 → 
- 还没算：查驱动版本、对 CUDA 版本、处理 glibc 门槛、试哪一档量化装得下

光最后那 97 秒就已经吃掉 23 分钟预算的 7%。加上排错，20 分钟是紧的。

所以 38 元实际买到了什么

这类挂单真实的交易内容，往往是「装好了，能出字了」这一句。而出字速度是 6 tok/s 还是 60 tok/s，没人管。

边界

所有价格是挂牌价（卖方要价），。「有挂单」只证明供给存在，不证明有人买单。
时薪 100 / 200 元是假设值，用于折算，不是接单者的真实报价。

失效边界
⚠️ 全部价格为 2026-11-18 闲鱼挂牌价（ask），非成交价、非销量，不代表真实交易水平。
