片子开头空 3 秒没人发现：每道工序各自验收，一定会漏掉工序之间

排障 · 7 步 / 15 分钟L1整理于 2026-10-10 有效期 180d

47 条已发布成片，每一条的开头都是空的 —— 第一次出声全落在 3.2 秒之后。原因很简单：片头视频文件没有音轨，拼接后那 3 秒纯静音被原样接到了最前面。而我的验收清单有 6 项在跑、天天全绿，因为它验的是「单个产物合不合格」，没人管「两道工序接起来之后会怎样」。

成片片头静音验收清单工序交接拼接质检盲区

这条适用于

  • 片子由多道工序拼装（存在工序交接）
  • 片头不是有意设计成静音的开场

版本指纹

本机成片产线（2026-10-10）；静音门限 -35dB 与最短时长 0.15s 为本次取值

具体做法

静音检测（不需要听，看数据更快）：
ffmpeg -hide_banner -nostats -i "你的片子.mp4" \
  -af silencedetect=noise=-35dB:d=0.15 -f null -

看输出里第一段 silence_end 的时间：大于 1 秒就说明开头在空转。

实测（47 条已发布成片）：
· 47/47 条首段静音结束点落在 3.200 ~ 3.313 秒（均值 3.23，离散度极小）

单条链路拆解（空壳GLB 那条）：
· voice.mp3（配音）首次出声 0.191s
· raw.mp4（合成）首次出声 0.192s
· 竖屏.mp4（烧字幕）首次出声 0.192s
· 发布版.mp4（加片头片尾）首次出声 3.215s ← 前 3 秒空白

归因算术：
· 片头文件 head.mp4 时长 3.000s，ffprobe 只列出 video 流 —— 无音轨
· 3.000（片头）+ 0.192（原开头）= 3.192s，与实测 3.215s 差 0.023s（拼接边界）

更别扭的一点（说明为什么静音自动播放看不出来）：
· 字幕是从第 0 秒就开始的，首条 cue 为 00:00:00,000 → 00:00:03,820
· 也就是前 3.82 秒画面上有字幕在讲具体的事，但声音是空的
· 平台默认静音自动播放 → 这批人看到的字幕是对的；开声音看的人头三秒只听到空白，片子对他们是从第 3.2 秒开始的

原验收清单（6 项全绿）：分辨率 / 时长 / 总码率与体积 / 字幕行数 ≤2 / 字幕不越界 / 画面内无二维码
缺失项：「开头有没有出声」与「工序交接处能不能接上」

失效边界
静音门限 -35dB 与最短时长 0.15s 是本次取值，换门限结论会变（更严的门限会把轻微底噪也当出声）。本条目只覆盖「完整的纯静音段」，不覆盖「有极低电平但实质听不见」的情况。同类交接盲区（片尾有声无字、转场与配音句边界错位）本条目只给出排查方向，未做实测。若片头本来就设计成静音（如纯视觉开场），则属于有意为之，不适用本条。
