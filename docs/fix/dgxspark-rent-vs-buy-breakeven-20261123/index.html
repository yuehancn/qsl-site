失效边界
1.  通常挂牌价高于成交价，但「买」和「租」两侧的偏离方向与幅度不一致，无法单向修正。
2.  若那 4 台不该按台均摊（比如共享带宽、单台反而更贵），62.5 偏低 → 「最不利于买」的 718 天偏悲观。
3. ，卖家集中在少数几个 ID 上，不代表全市场价格分布。
4.  驱动、CUDA、集群互联的调试成本未计入 ——折进去只会让回本点更长，不会更短。
5.  本篇是纯硬件取得成本对比，不是完整 TCO。
