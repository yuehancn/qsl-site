每 GB 单价一个价，但 5060Ti 和 DGX Spark 卖的不是同一样东西

成本账 · 4 类硬件 / 39 条有效挂单 / 每 GB 259–1,108 元未标注整理于 2026-11-14 有效期 30d

把二手挂牌价做一次除法，四类硬件的每 GB 单价几乎撞在一起：RTX 5060Ti 16GB 中位 ¥5,300（13 条）折 ¥331/GB、DGX Spark 128GB ¥41,450（8 条）折 ¥324/GB、Mac Studio 512GB ¥181,888（17 条）折 ¥355/GB，三者只差几十块；而 RTX 5090D 32GB ¥35,450（1 条）折 ¥1,108/GB，是前三者的三倍多。单价对齐不等于等价：5060Ti 与 5090D 卖的是带宽，DGX Spark 与 Mac Studio 卖的是容量。同样一万元，DGX Spark 换 30.9GB 内存、5090D 只换 9.0GB 显存（3.4 倍容量），代价是带宽差 7.7 倍。

具体做法

【四类硬件每 GB 单价（二手挂牌价，2026-11-13 23:31 采集，口径 = ask）】
RTX 5060Ti 16GB    中位 ¥5,300   13 条   ¥331/GB   区间 4,650–6,666
DGX Spark 128GB    中位 ¥41,450   8 条   ¥324/GB   区间 33,199–400,000（p25 36,999 / p75 81,249 / cv 1.24）
Mac Studio 512GB   中位 ¥181,888  17 条   ¥355/GB   区间 135,888–200,000
RTX 5090D 32GB     中位 ¥35,450   1 条   ¥1,108/GB （样本 1 条，不给分位数）
【这张表最该看的两点】
一、前三者单价撞在一起（324 / 331 / 355），但它们是三种完全不同的东西：
    5060Ti = 16GB 独占显存，1792 GB/s 系那一档的高速 GDDR7；
    DGX Spark = 128GB 统一内存，实测 copy 233.6 GB/s；
    Mac Studio = 512GB 统一内存，容量最大、单价也不高。
二、5090D 的单价是前三者的三倍多，而它的容量只有 32GB —— 它卖的是带宽，不是容量。
【同样一万元能换多少】
DGX Spark：10,000 ÷ 324 = 30.9 GB
RTX 5090D：10,000 ÷ 1,108 = 9.0 GB
→ 3.4 倍容量差，换 7.7 倍带宽差（233.6 / 1792 的倒数口径：5090D 带宽是 DGX Spark 实测值的 7.7 倍）。

【DGX Spark 统一内存的实测口径（四台独立复测）】
copy 512MB：224.5 / 226.9 / 230.5 / 233.6 GB/s（四台离散度 3.4%）
标称 273 GB/s → 四台达成率 82.7%–85.6%
MemTotal：121.69 GiB/台（厂商标称 128GB 是十进制口径）
容器内 nvidia-smi 占用：94.43 GiB（≠ 128，也 ≠ 121.69，三个数都不是一回事）

【RTX 5090D 的 1792 GB/s 是官方公开规格，不是本机实测】
NVIDIA 官方页与多方资料一致：32GB GDDR7、512bit 位宽、1792 GB/s 总带宽、建议零售价 16,499 元起。
本文只用它做「带宽 vs 容量」的换算，未在本机跑带宽基准。

【样本量的坑】
DGX Spark 8 条挂单里，最高的 400,000 是「4t 老黄版 ×8 + 迈洛思 SN3700 整套」，
最低 33,199 是单机实价（新华三 H3C MegaCube 128G 1T）。
按最低价算每 GB 是 259 块，比 5060Ti 的 331 还便宜 72 块。
同一批挂单，单价能从 259 算到 3,125 —— 样本这么散时，中位数比均值可信，但都不如自己去看那几条具体写了什么。

失效边界
全部价格为二手挂牌价（卖方要价），不是成交价、不是销量；「有挂单」只证明供给存在。RTX 5090D 仅 1 条、A100 80G 租仅 2 条，按规则不给分位数，其单价不可外推。5090D 的 1792 GB/s 是 NVIDIA 官方公开规格，本机未做带宽基准。DGX Spark 的 233.6 GB/s 是 copy 512MB 实测，与「只读带宽」不是同一口径，跨口径比较会偏差约 11%。统一内存与显存是两种不同口径，本文已分别标注，未做等价处理；「DGX Spark 装得下某模型」只表示容量够，不代表推理速度可接受。价格随行情波动，本文快照仅代表 2026-11-13 23:31 这一时刻。
