四台 DGX Spark、每台 2× ConnectX-7（链路 200000 Mb/s、MTU 9000），四对双向单流 TCP 各搬 8 GiB，**14 次实测均值 39.11 Gbps = 19.6%**，全部落在 36.2–44.1 的窄带里。三件事排除了「网坏了」：双向只差 2.7%、四对全在同一窄带、环网 RTT 0.026–0.051 ms 比千兆管理网快 9.5–18.7 倍。**延迟拿到了、吞吐没拿到 ⇒ 不是不通，是通但只给一小部分。**按 200G 规划的事，时间要乘 5.1 倍；但相对千兆仍快约 40 倍，这笔钱没白花。
