具体做法

实证：同一 white_bg 文件前后两次质检都是 1214164 字节，bg_purity 从 0.4504 变 0.7122 即通过；同一 cutout 文件两次都是 706048 字节，need_alpha 从 false 变 true 即通过。另发现两个 33 字节的空壳 PNG（读图失败写占位桩）。修正口径后五张里只有 3 张真需返工。

失效边界
该做法假定质检脚本与产物形态可建立映射；若产线把多个步骤合并成一个工作流输出、无法按步骤区分产物，需先拆分输出节点（按 filename_prefix 分目录）再套用。阈值仍需按自己的模型与场景标定，本文数值不可直接照搬。
