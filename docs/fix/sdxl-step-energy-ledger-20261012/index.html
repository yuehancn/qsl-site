SDXL 步数翻三倍，一万张电费只多 2.61 元：瓶颈是机器小时

成本账 · 5 步 / 15 分钟未标注整理于 2026-10-12 有效期 30d

把 SDXL 步数从 16 加到 48（翻三倍），一万张图的电费只从 1.38 元涨到 3.99 元（多 2.61 元），但机器时间从 4.79 小时涨到 12.20 小时（多 7.41 小时）。功耗峰值在整条步数梯度上恒定 581±3 瓦 —— 步数只改变「满载持续多久」，不改变「满载多深」。空载仅 6.29 瓦。省电不是调低步数的理由，省机器时间才是。

RTX 5090D 32GB 单卡 / ComfyUI 0.33.0 / 1024×1024（2026-10-12）

具体做法

实测（本机 RTX 5090D + ComfyUI 0.33.0 + sd_xl_base_1.0，2026-10-12，1024×1024 / CFG 7.0，功耗用 nvidia-smi 每 0.08-0.10 秒采样）：

功耗基线：
· 空载（ComfyUI 常驻无任务）6.29 W / 显存 13573 MiB
· 采样峰值 580.7-584.1 W（整条步数梯度恒定 581±3 W）
· 平均功耗 280.9 W（1步）→ 545.1 W（48步）

一万张外推（@0.6 元/kWh）：
· 8 步 1.035s / 0.11883Wh → 2.88h / 0.71 元
· 16 步 1.723s / 0.23021Wh → 4.79h / 1.38 元
· 20 步 2.037s / 0.26795Wh → 5.66h / 1.61 元
· 24 步 2.436s / 0.35236Wh → 6.77h / 2.11 元
· 32 步 3.002s / 0.43574Wh → 8.34h / 2.61 元
· 48 步 4.391s / 0.66489Wh → 12.20h / 3.99 元

16→48 步：时间 2.55×、能耗 1.89× —— 多 7.41 机器小时，电费只多 2.61 元。

失效边界
单张耗时与单张能耗为本机实测中位数；「一万张」是按单张数值得到的量级参考，非实测总量（大批量下的热稳态与首次加载摊薄会带来偏差）。电价按 0.6 元/kWh 估算，各地不同。换硬件（功耗曲线不同）或分辨率后数值会变。
