Mac mini 跑 224B 模型：要 99.1% 命中率，比 DGX Spark 高 2.4 个百分点

成本账 · Mac mini 跑 224B 模型：要 99.1% 命中率，比 DGX Spark 高 2.4 个百分点未标注整理于 2026-11-27 有效期 permanent

125.73 GiB 的 224B 模型装进 64 GB 统一内存，官方解法是 Strata offload（按需从盘搬）。于是「能不能跑」变成了「缓存能热到什么程度」。按 config 推算，跑到 10 tok/s 需要：**DGX Spark 96.7% / 96.8%，Mac mini M6 要 99.1%** —— 盘最快的机器反而要求最高的命中率，因为它**没有多流余量**（T=2 只涨 4.7%，11.2 GB/s 是天花板）。买它的钱实际上是买「你必须一直用同一个模型」这个约束：换一次模型、重启一次，缓存清零重攒。
