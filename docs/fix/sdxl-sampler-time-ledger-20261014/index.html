SDXL 采样器耗时差 64%、画面差与耗时无关：euler 与 ddim 同 seed 出图逐像素一致

性能 · 5 步 / 20 分钟未标注整理于 2026-10-14 有效期 30d

同 seed / 同 20 步 / 同 1024² 下，11 个采样器耗时从 lms 2.186 秒到 dpmpp_2s_ancestral 4.137 秒（差 64%），但画面变化与耗时无关：慢的 heun（3.950s）RMS只有 17.51，快的 dpmpp_2m_sde（2.770s）RMS 反有 39.79。另外 euler 与 ddim 在同 seed 下输出逐像素一致（最大差值 0），ddim 还快 7%。调度器则相反：7 个耗时极差仅 0.23 秒（11%），画面 RMS 最大到 16.24。

实测（本机 RTX 5090D 32GB + ComfyUI 0.33.0 + sd_xl_base_1.0，2026-10-14，1024² / 20 步 / CFG 7.0 / batch 1 / 同 seed，各 3 次取中位）：

采样器耗时与画面差异（RMS 相对 euler，0–255）：
· lms 2.186s / RMS 11.58
· dpmpp_2m 2.197s / RMS 15.68
· euler_ancestral 2.235s / RMS 30.10
· res_multistep 2.260s / RMS 17.26
· uni_pc 2.273s / RMS 23.74
· ddim 2.351s / RMS 0.00（与 euler 逐像素一致，最大差值 0，md5 不同）
· euler 2.523s / RMS 0.00（基准）
· dpmpp_2m_sde 2.770s / RMS 39.79
· heun 3.950s / RMS 17.51
· dpm_2 4.074s / RMS 18.54
· dpmpp_2s_ancestral 4.137s / RMS 34.43

调度器（@euler）：耗时 2.089–2.319s（极差 0.23s = 11%），RMS 相对 normal：sgm_uniform 5.78 / exponential 7.50 / karras 9.37 / beta 9.97 / ddim_uniform 13.86 / linear_quadratic 16.24。

成本外推：两千张 1024²，euler 约 84 分钟，dpmpp_2s_ancestral 约 138 分钟 —— 差 54 分钟（约 600W 满载占用）。

失效边界
本结论为本机实测（RTX 5090D 32GB / 驱动 591.86 / ComfyUI 0.33.0）。像素 RMS 只衡量「与基准图的差异程度」，不等于画质评分；「哪张更好看」需自行判断。每组仅 3 次重复；不同驱动 / 框架版本数值会变。测前已停止占卡进程。
