16GB 显存卡的产线策略：不要试图用小卡追大卡

成本账 · 约 30 行配置L0整理于 2026-09-30 有效期 180d

实测证明：16GB 卡加大 batch 追 5090D，差距会从 3.35 倍扩大到 3.89 倍。正确做法是降并发、拉长单张、用常驻进程吃掉冷启动。

显存优化ComfyUI硬件选型产线

这条适用于

  • 显存落在 16GB 档（如 5060Ti）
  • 要跑的是批量出图或大模型（Flux / 视频模型）

版本指纹

5060Ti 16G；batch=4 峰值 15922MB；2026-09 本机基线

具体做法

# 16GB 卡的推荐配置（不要照搬大卡参数）
batch_size: 1          # 不要拉到 4，会撞显存墙
resident_process: true # 常驻，禁止每次重启
keep_model_loaded: true
# 判断是否会撞墙：预留安全余量
VRAM_TOTAL = 16311  # MiB
SAFE_LINE  = 15000  # 留 1GB 给系统与显存碎片
# SDXL 单张峰值 12471 -> 安全
# SDXL batch4 峰值 15922 -> 仅剩 389MiB，危险，不要上产线
失效边界
显存墙是最容易低估的坑：batch=4 时 5060Ti 峰值 15922MB，只剩 389MiB 余量，看着能跑但已经顶到天花板。换更大模型（Flux fp8 单文件就 16GB，Wan2.2 5B 视频模型）大概率回退到共享内存，速度断崖式下跌 —— 这也解释了为什么某些 5060Ti 主机上装的是 wan2.1_t2v_1.3B 而不是 5B。
