本地写稿成本分三层：每千字电费 0.0018 元，最贵的是重跑判断时间

成本账 · 每千字 0.0018 元 · 拆轮 vs 单次L1整理于 2026-10-18 有效期 30d

本机 5090D + Ollama 0.40.4 + qwen2.5:14b 的写稿成本结构账。单位成本：出字阶段净功耗 353–423 W（实测均值 400–470 W 减空载 47 W），decode 136.34–138.92 token/s，汉字/token 约 1.1，折算每秒约 150 汉字；按 0.55 元/kWh 计，每千字电费 0.0018 元，一篇 1800 字稿电费约三分钱。成本结构分三层：电费可忽略、判断与重跑时间最贵、卡的时间只有长输出才明显。生产方式对照（同一主题 8 小节）：单次调用要求 3000 字，两组出 1508 / 1725 汉字、墙钟 8.04 / 8.73 s、净能耗 0.6995 / 0.8553 Wh、5-gram 重复率 0.0645 / 0.0999；拆 4 轮各 2 小节，两组出 1688 / 1715 汉字、墙钟 8.61 / 8.71 s、净能耗 0.7528 / 0.7906 Wh、5-gram 重复率 0.0392 / 0.0199、段间最大重叠 0.0286 / 0.0163。

版本指纹

Windows 11 + RTX 5090D 32GB；Ollama 0.40.4；qwen2.5:14b（Q4_K_M）；电价按 0.55 元/kWh 估算

具体做法

环境：本机 RTX 5090D 32GB / Ollama 0.40.4 / qwen2.5:14b（Q4_K_M），2026-10-18。与同批「输出长度天花板」实测同机同模型，但本条目只算单位成本与两条生产路线对比，数据不重叠。

【单位成本折算】
· 出字阶段净功耗 353–423 W（均值 400–470 W 减空载 47 W）
· decode 136.34–138.92 token/s（五档极差 1.9%）
· 汉字 / token ≈ 1.1 → 每秒约 150 汉字
· 每千字电费 = 0.0018 元（0.55 元/kWh）
· 一篇 1800 字稿电费约 0.003 元
【两条生产路线对照（同一主题 8 小节）】
· 路线A 单次调用要求 3000 字
  - 汉字 1508 / 1725（均值 1616）
  - 墙钟 8.04 s / 8.73 s
  - 净能耗 0.6995 / 0.8553 Wh
  - 5-gram 重复率 0.0645 / 0.0999
· 路线B 拆 4 轮，每轮只讲 2 小节、约 750 字
  - 汉字 1688 / 1715
  - 墙钟 8.61 s / 8.71 s
  - 净能耗 0.7528 / 0.7906 Wh
  - 5-gram 重复率 0.0392 / 0.0199
  - 段间最大 5-gram 重叠 0.0286 / 0.0163
→ 字数：拆轮一次多 13%、一次少 2%（不稳定，不可作为收益主张）
→ 重复率：拆轮两组一致显著更低（稳健结论）

【本轮真实重跑次数】
· 调参过程共 8 次重跑，两个多小时（含判断与改指令），电费不到 0.01 元

失效边界
本结论为本机实测（2026-10-18；RTX 5090D 32GB / Ollama 0.40.4 / qwen2.5:14b Q4_K_M）。汉字与 token 的换算比按本机实测输出估算（约 1.1），不同模型与内容类型会有差异，不是理论值。功耗为 nvidia-smi 0.2 s 一次采样后积分，已扣空载基线 47 W。电价按 0.55 元/kWh 估算，仅用于量级判断。拆轮的字数优势在两组复测中不一致（+13% / −2%），本条只主张重复率优势，不主张产量优势。未与云端 API 做成本对比——两者计费口径不同，不做跨口径外推。
