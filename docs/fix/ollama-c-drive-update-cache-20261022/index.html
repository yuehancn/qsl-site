改了 OLLAMA_MODELS 也只搬走一半：Ollama 在 C 盘还留 4.35 GiB

环境与安装 · 4.350 GiB · 1.540 GiB 安装包 · 占模型库 50.4%L0整理于 2026-10-22 有效期 30d

把 OLLAMA_MODELS 指到 D 盘只解决了「模型权重放哪」，解决不了「程序本体放哪」和「安装包放哪」。本机实测（Ollama 0.40.4 / Windows 11）：D:\models\ollama 里是 9,262,433,074 字节 = 8.626 GiB / 13 个文件（两个模型的 9 个 blob）；但 %LOCALAPPDATA%\Programs\Ollama 还有 3,001,340,310 字节 = 2.795 GiB / 996 个文件（Inno Setup 装的程序本体），%LOCALAPPDATA%\ollama 还有 1,668,939,634 字节 = 1.554 GiB / 18 个文件（数据、日志、更新包）。三处 C 盘合计 4,670,279,944 字节 = 4.350 GiB，等于 D 盘模型库的 50.4%。其中最能白拿的一块是 updates_v2\<64位哈希>\OllamaSetup.exe = 1,657,983,656 字节 = 1.540 GiB，修改时间 2026-10-21 15:50——装完了、日志写了 Installation process succeeded.，包还在。这个缓存按内容寻址分目录（每次新版是另一个哈希、另一个目录），设计意图是同一包只存一份，但装完不回收，也永不自动清。upgrade.log 已 426,200 字节 / 5,053 行，摞着 5 次安装记录。可安全清的就是 updates_v2 这一层；Programs\Ollama 那 2.795 GiB 别手搬——Inno Setup 装的，注册表和卸载项都指向原路径，搬了升级会出问题。

Ollama本地部署C盘磁盘占用OLLAMA_MODELSupdates_v2安装包缓存清理Windows环境变量模型目录

这条适用于

  • Windows 桌面版 Ollama（Inno Setup 安装），且已把 OLLAMA_MODELS 指向非 C 盘
  • C 盘空间按「模型进 D 盘、C 盘只留系统」管理，才需要核这处残留

版本指纹

Ollama 0.40.4 + Windows 11 10.0.26200；OLLAMA_MODELS=D:\models\ollama

具体做法

环境：本机 Windows 11（10.0.26200）/ Ollama 0.40.4 / OLLAMA_MODELS=D:\models\ollama，2026-10-22 凌晨实测（os.walk 累加文件字节，已排查无软链接重复计算）。

失效边界
本结论为本机磁盘级实测（2026-10-22 凌晨，Ollama 0.40.4 / Windows 11 10.0.26200），体积由 os.walk 累加文件字节数得出，并已排查目录内无软链接/junction 造成重复计算。数字是单机单时刻快照，随版本更新会变。删除 updates_v2 的行为只确认「是下载缓存、不影响已装程序与 D 盘模型」，未在本文中代为执行删除；执行前请自行核对路径，并确认 %LOCALAPPDATA%\ollama 整个目录不要删（内 db.sqlite 等运行数据）。Programs\Ollama 不建议手动搬迁。
