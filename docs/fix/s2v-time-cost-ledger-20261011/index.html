· 文案 234 字 → 切 7 段
· 16:06:36 开始切段 → 16:26:52 出片 = 20 分 16 秒

对照组（同一产线的图文形态）：
· 几十秒成片端到端 70 ~ 100 秒（分镜图 + 推拉镜头）
· 差别只在画面是「画一次用满 8 秒」还是「逐帧重画对口型」

缓存行为：
· 输入指纹（文案 / 音色 / 形象任一）变化 → 清空段缓存 → 20 分钟重跑
· 输入不变、中途中断 → 段级缓存全部命中 → 从 20 分钟降到 1 秒

策略结论：
· 图文形态 = 日常口粮，可日更、可批量试选题
· 口播形态 = 一次做多次用的资产，文案一次定稿、绝不中途改字重跑
失效边界
本文的耗时是本机单机实测（RTX 5090D，480×832，5 步采样，每 8 秒切一段），换分辨率、采样步数、切段长度，数值会成比例变化，不能直接套用。「每 1 秒画面约 23 秒」是本次取值的换算，不是该形态的理论下限。S2V 逐帧重绘的计算性质部分为基于本机现象与公开资料的推断，非厂商说明。本条目只算时间成本，不涉及画质与口型自然度的评价。
