具体做法

我原以为「分时段」只是输出价打个折，逐档拉出来才发现三档全是 2 倍：输入缓存命中 0.02/0.04、缓存未命中 1/2、输出 4/8（元每百万 tokens）。

这一点很重要。如果只有某一档打折，你就得去优化 token 结构才能吃到折扣；三档同倍数意味着，只要把任务挪到空闲时段就行，不用改代码、不用压提示词。

把云端价格当尺子量本地：一台官网标价 6999 的 16G 机器。

轻度用法（月输入 2000 万，八成缓存命中，输出 200 万）：月账单 12.32 元 → 568 个月回本，约 47 年。
重度用法（月输入 2 亿，同样八成命中，输出 2000 万）：月账单 123.2 元 → 56.8 个月，约 4.7 年。

同一台机器，回本时间差 10 倍。决定本地值不值的不是硬件参数，是你的月用量。

所以对绝大多数人，本地部署在纯成本上算不过来，而且差得很远。硬件真正的价值不在省钱，在于数据不出门、断网能用、想改什么就改什么。

失效边界
1. （轻度 2000 万输入 / 重度 2 亿输入，均按八成缓存命中），不是平台公布的典型用户画像。你的实际用量会得出不同结果。
2. ，不含限时活动或代金券，随时可能调整；实际扣费以平台账单为准。
3. ，只有算术推导。
4. ，未计电费、未计折旧、未计你自己的时间成本 —— 真实回本只会更长，不会更短。
