5090D 与 5060Ti 怎么选：价差 4.96 倍只买到 3.35 倍速度，每万张成本反而更高

性能 · SDXL 1024x1024 / batch1 与 batch4 / 双卡同条件未标注整理于 2026-11-11 有效期 180d

SDXL 1024x1024 单张：5090D 4.98 秒 对 5060Ti 16.68 秒（3.35 倍）。2026-11-11 实采价：5090D 32GB 33,200 起、5060Ti 16GB 6,699，价差 4.96 倍。batch4 每张摊薄 4.17 对 16.25 秒（3.9 倍），显存余量 9,100MB 对 389MB（23 倍）。三年 8h 打满摊到每万张：57.4 元 对 45.1 元，贵的反而高 27%。结论反转：5090D 的理由只剩交付窗口与单卡显存上限。

这条适用于

  • RTX 5090D 32GB 与 RTX 5060Ti 16GB 各一台
  • ComfyUI + SDXL 基础模型已跑通
  • 同一套提示词与 seed 配置，两张卡同条件对照

版本指纹

ComfyUI 0.33.0 / torch 2.8 / CUDA 12.9

具体做法

实测环境：RTX 5090D 32GB（主力工作站）与 RTX 5060Ti 16GB（素材产出机）各一台，
同一套 ComfyUI + SDXL 基础模型，1024x1024，batch 1 与 batch 4 各测。
基线 2026-09-26 三次取中位，2026-10-02 复测。

【速度】
单张 1024x1024：4.98 秒 对 16.68 秒（3.35 倍）
batch4 单批：16.69 秒 对 64.99 秒；每张摊薄 4.17 秒 对 16.25 秒（3.9 倍）
100 张 batch1：498 秒（8.3 分钟）对 1668 秒（27.8 分钟），差 19.5 分钟
100 张 batch4：417.25 秒 对 1624.75 秒
竖屏 768x1344：5.09 秒 对 16.54 秒
冷启动：5.03 秒 对 25.72 秒（5.11 倍）

【显存】
batch4 峰值占用：23,507 MB 对 15,922 MB
batch4 余量：9,100 MB（27.9%）对 389 MB（2.4%），余量比 23.39 倍，占用比 1.48 倍

【成本（电费 0.6 元每度，摊销三年）】
每千张耗电：0.70 度（0.42 元）对 1.58 度（0.95 元）
每万张硬件摊销：52.4 元 对 35.4 元（3年 8h/天 打满）
显卡参考价（2026-11-11 采集）：32,200 元区间最低 33,200 对 6,699 元（4.96 倍）
每万张合计：57.4 元 对 45.1 元 —— 5090D 反高 12.3 元（27%）

失效边界
价格为 2026-11-11 实采（5090D 32GB 33,200-35,990；5060Ti 16GB 京东常卖 6,699，史低 4,039），会变动，读者须自行复核。只谈 32GB 与 16GB 两个版本，5090D V2 24GB 与 5060Ti 8GB 是不同价格口径。摊销按三年 8h/天打满，跑不满时两卡同比例上升。电费按 0.6 元每度估算，各地电价不同。所有速度与显存数字为本机实测，但只覆盖 SDXL 这一个工作负载，视频生成、训练、大参数量化的结论可能不同。
