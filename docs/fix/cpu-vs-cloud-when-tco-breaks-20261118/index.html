纯 CPU 本地跑 7B 的账：一小时 24,023 token，抵不过一台机器的钱

成本账 · 1 台机器 / 1 个模型 / 2 档对照未标注整理于 2026-11-17 有效期 permanent

Xeon E5-2673 v4 纯 CPU 跑 7B Q4_K_M，出字稳定在 6.67 tok/s（20 线程），一小时最多 24,022.86 个 token。按整机 200W 估，一小时 0.2 度电、约 0.11 元。电费不是问题。问题是这台机器的钱：128GB 内存的双路服务器，即便按二手价也是四位数到五位数。这个产出量换成云端 API，价钱是几块钱量级。所以纯 CPU 跑大模型这条路，账不算在电费上，算在「这台机器本来就在那儿」上。它的真实价值是离线、数据不出门、不受配额限制，不是便宜。

纯CPU推理回本云API成本本地部署7BTCO

这条适用于

  • 能用功率计测整机功耗
  • 有连续 60 秒以上的稳态 tok/s

版本指纹

qwen2.5 7B Q4_K_M + llama-bench b12451

具体做法

【实测与计算】
  7B Q4_K_M（4,677,120,000 B）@20 线程 decode = 6.673016 tok/s
  一小时产出 = 6.673016 x 3600 = 24,022.86 token
  1.5B 对照：27.713532 tok/s -> 一小时 99,768.72 token
【电费（按 200W、0.55 元/度）】
  0.2 kWh -> 0.11 元/小时
  ⚠ 200W 是估算，未经功率计实测。双路 E5 满载常高于此值。
【关键判断】
  每小时 2.4 万 token 的量，云端按主流 API 价位是几块钱。
  所以纯 CPU 跑大模型的正当理由不是「省 API 费」，是离线 / 数据不出门 / 无配额。
  如果只为省钱买一台双路服务器，回本周期会远长于硬件寿命。
失效边界
功率 200W 是估算不是实测，未用功率计核对。云端 API 价格未在本文取当日实际报价，只作量级参照，未给出具体金额对比。折旧年限与每日运行时长未固定，故不给回本周期结论。只覆盖 7B Q4_K_M 一档，更大模型会显著更慢（权重体积线性放大）。
