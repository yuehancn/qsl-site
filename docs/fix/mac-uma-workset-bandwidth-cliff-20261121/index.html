Mac 统一内存：11.84 GiB 不是墙，10 GiB 就开始掉速

成本账 · 16GB 统一内存 / 11.84 GiB 建议线 / 10 档带宽阶梯未标注整理于 2026-11-21 有效期 permanent

一台 M6 / 16GB 的 Mac mini，mx.device_info() 报 max_recommended_working_set_size = 12,713,115,648 B（11.840 GiB）。实测它不是墙：40 步 × 0.5 GiB 一直分配到 20.0 GiB，零 MemoryError，peak 21.0 GiB。真正的形态是带宽断崖，而且断崖在上限之前就开始了——6 GiB 驻留时 512 MiB 张量求和 3.80 ms（141.21 GB/s），10 GiB 时 7.08 ms（75.8 GB/s，只剩 54%），11.5 GiB 时 38.81 ms（13.8 GB/s，掉 5.54 倍），13 GiB 时 255.05 ms（2.1 GB/s），14 GiB 时 1755.34 ms（0.31 GB/s）且 swap 从 914 MB 涨到 2940 MB。同法对照 GB10（121.68 GiB 统一内存）：驻留 2→24 GiB 带宽 63.75→61.54 GB/s，只降 3.47%，全程平坦无换页。结论：16GB Mac 的全速区在 10 GiB 以下，不是 11.84 GiB。

Mac统一内存MLXMetal工作集上限swap带宽断崖16GB24GB选型

这条适用于

  • macOS + MLX 环境（本例 0.32.4）
  • 至少 16GB 统一内存的 Apple Silicon 机器
  • 测试时关闭后台大内存进程，避免干扰高低档对比

版本指纹

MLX 0.32.4 / macOS 27.2.1 / Apple M6

具体做法

【实测口径】
  机型：Apple M6 12 核 / 16GB 统一内存 / macOS 27.2.1 / MLX 0.32.4
  设备原值（mx.device_info）：memory_size 17,179,869,184 B（16.000 GiB）；max_recommended_working_set_size 12,713,115,648 B（11.840 GiB）；max_buffer_length 9,534,832,640 B（8.880 GiB）；resource_limit 499000
【分配不失败（40 步 × 0.5 GiB，保持驻留）】
  ALLOC_OK chunk=1 ... ALLOC_OK chunk=40（无一次 MemoryError）
  FINAL total_alloc_bytes 21,474,836,480 = 20.0 GiB；active 20.5 GiB / peak 21.0 GiB
【带宽阶梯（512 MiB fp16 随机张量单次 sum，带宽 = 512 MiB ÷ 耗时）】
  驻留  6.0 GiB →    3.80 ms → 141.21 GB/s（swap —）
  驻留 10.0 GiB →    7.08 ms →  75.8  GB/s（swap 914 MB）
  驻留 10.5 GiB →    6.94 ms →  77.4  GB/s（swap 914 MB）
  驻留 11.0 GiB →    7.02 ms →  76.5  GB/s（swap 914 MB）
  驻留 11.5 GiB →   38.81 ms →  13.8  GB/s（swap 1017 MB）
  驻留 12.0 GiB →   39.69 ms →  13.5  GB/s（swap 1032 MB）
  驻留 12.5 GiB →   40.01 ms →  13.4  GB/s（swap 1015 MB）
  驻留 13.0 GiB →  255.05 ms →   2.1  GB/s（swap 1280 MB）
  驻留 14.0 GiB → 1755.34 ms →   0.31 GB/s（swap 2940 MB）
【独立复现（读全部驻留张量求和，宽档跨 2 GiB）】
  2 → 98.63｜6 → 140.59｜10 → 76.00｜11 → 21.77｜12 → 6.95｜14 → 0.31｜16 → 0.24 GB/s
【GB10 对照（8 线程 × 128 MiB memcpy，MemTotal 121.68 GiB）】
  驻留 2 / 6 / 10 / 12 / 16 / 24 GiB → 63.75 / 64.08 / 64.85 / 65.45 / 64.08 / 61.54 GB/s
  2 GiB → 24 GiB 降 3.47%；峰值 10 GiB 64.85 → 24 GiB 61.54 降 5.10%，无换页
【价格（2026-11-20 采集）】
  Mac mini M6 12C / 16GB / 256GB：6,999 元（apple.com.cn 官网）
  内存 16GB→24GB 加价 1,500 元 → 24GB 版 8,499 元；折 187.5 元/GB
失效边界
【未测到的，一律不许当结论】
1. 24GB / 32GB 机型一台都没测。24GB 的「建议线约 17.8 GiB」是按 16GB 的 74% 比例外推的算术，不是实测。
2. 11.0 与 11.5 GiB 之间的断点没二分到 0.1 GiB，只知落在这 0.5 GiB 区间内。
3. M4 / M5 / M5 Pro 全没复现，结论仅限本机 M6 16GB。
4. max_recommended_working_set_size 的官方语义没读 Apple 原文，只按实测行为描述为「建议线」，不写「硬上限」。
5. Mac 侧带宽绝对值未取到（8×64 MiB 测出 437-485 GB/s 属 SLC 命中，判无效）。因此只给「驻留量变化时带宽怎么变」的相对结论，不含 M6 峰值带宽，跨机带宽绝对值对比不成立。
6. 11.0 GiB 这一档两轮差异大（21.77 vs 76.5 GB/s），判为后台负载干扰，该点存疑。
7. 全部带宽为单次求和换算值，未做多轮误差棒。
8. 模型本体没跑，本篇零 tok/s。
