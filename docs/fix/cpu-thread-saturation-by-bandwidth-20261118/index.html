纯 CPU 跑本地模型：先用带宽反算线程饱和点，不要按核数给

环境与安装 · 1 台机器 / 2 个模型 / 6 档线程未标注整理于 2026-11-17 有效期 permanent

纯 CPU 跑大模型，出字（decode）速度和读文档（prefill）速度对线程数的反应完全相反。Xeon E5-2673 v4 双路 80 线程实测：7B Q4_K_M 从 8 线程加到 20 线程，出字只快 0.52%（6.6382 到 6.6730 tok/s）；同一台机器同一参数，读文档涨 137.71%（30.4837 到 72.4619 tok/s）。把 decode 的 tok/s 乘回权重字节数，得到隐含带宽 30.54 / 31.05 / 30.80 / 31.21 GB/s —— 两个体积差 4.2 倍的模型、8 与 20 两个线程档，四个数全落在 30.5 到 31.2 之间。意思是 decode 的墙是内存带宽，不是核数。线程给多了，多出来的核在排队等内存。

纯CPU推理线程数内存带宽llama.cpp本地部署decodeprefill调优

这条适用于

  • llama.cpp b12451 或更新
  • 内存通道尽量插满（本例只插一半，饱和点提前）
  • 测试期间尽量清空背景负载

版本指纹

qwen2.5 1.5B/7B Q4_K_M + llama-bench b12451

具体做法

【实测口径】
  机器：Intel Xeon E5-2673 v4 @ 2.30GHz，双路 2x20C，nproc 报 80，128GB（4x32GB / 2133 MT/s / 每 NUMA 节点 1 条）
  绑定：taskset -c 0-19（NUMA0）
  命令：llama-bench -p 128 -n 64 -t {1,2,4,8,16,20} -r 2
  模型：qwen2.5-1.5b-instruct-q4_k_m（1,111,370,240 B）、qwen2.5-7b-instruct-q4_k_m（4,677,120,000 B，两分片）

【1.5B decode tg64 tok/s】1: 7.8349 / 2: 13.4601 / 4: 23.0996 / 8: 27.4812 / 16: 27.7258 / 20: 27.7135
【1.5B prefill pp128 tok/s】1: 22.2662 / 2: 39.6986 / 4: 72.2794 / 8: 147.8808 / 16: 270.5759 / 20: 321.2659
【7B decode tg64 tok/s】1: 1.7408 / 2: 3.2458 / 4: 5.5481 / 8: 6.6382 / 16: 6.7283 / 20: 6.6730
【7B prefill pp128 tok/s】1: 4.6584 / 2: 8.3334 / 4: 15.2216 / 8: 30.4837 / 16: 60.5002 / 20: 72.4619

【隐含带宽（权重 B x tok/s）】
  1.5B @8: 30.54 GB/s   @20: 30.80 GB/s
  7B   @8: 31.05 GB/s   @20: 31.21 GB/s
  ⇒ 四个数落在 30.5-31.2 GB/s，与线程数和模型体积都无关
【8 到 20 线程的涨幅】
  1.5B decode +0.85%   ｜ 7B decode +0.52%
  1.5B prefill +117.25% ｜ 7B prefill +137.71%
【1 到 20 线程的总加速】
  1.5B decode 3.54 倍 / prefill 14.43 倍
  7B   decode 3.83 倍 / prefill 15.56 倍
【小模型对大模型的速度比（同带宽应等于权重反比 4.21）】
  @8 线程 decode 4.14 倍｜@20 线程 decode 4.15 倍 → 与 4.21 基本吻合
失效边界
内存带宽是从 tok/s 反算的隐含值，不是用 STREAM 之类工具独立测出来的。标称带宽没有在这台机器上取得官方确认，「26% 达成率」是按 120 GB/s 推算，不是实测。Python 多线程微基准在本机被 GIL 卡死（单线程 1.16 GB/s，8/20 线程反降到 0.54/0.50 GB/s），该组作废，不能引用。测试期间机器有背景负载：loadavg 起始 32.01、结束 13.69，绝对值偏保守，同机横向对比仍成立。只测了 x86 这一台，另一台 ARM 机器（DGX Spark）20 线程档抖动过大（三次采样 29.42/23.33/24.32）未采信。未测并发、未测 KV 增长对速度的影响。
