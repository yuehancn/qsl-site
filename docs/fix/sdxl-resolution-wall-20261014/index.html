SDXL 出大图的墙不是显存，是训练画布 1024：超过 1536 主体就开始复制

性能 · 6 步 / 25 分钟L0整理于 2026-10-14 有效期 30d

本机 5090D 把 SDXL 从 512 一路加到 4096²，32GB 显存峰值 32064 MiB 也没 OOM；4096² 单张 72.948 秒，是 1024²（2.259 秒）的 32.3 倍。真正崩的是画面：1024² 是一座灯塔，2048² 变两座，4096² 礁石上站了一排。量化后亮区连通域数 21（1024）→46（2048）→111（4096），主峰占比 2.39%→1.63%→0.43%。显存斜率约 1527 MiB/MP，底座 5.5–6.5GB 与画布无关。

  • 本机 RTX 5090D 32GB，ComfyUI 0.33.0，1024² 起步逐档放大

具体做法

实测（本机 RTX 5090D 32GB + ComfyUI 0.33.0 + sd_xl_base_1.0，2026-10-14，steps 20 / CFG 7.0 / euler+normal / batch 1，每档 3 次取中位）：

分辨率梯度（时间 / 显存峰值）：
· 1024²（1.05MP）= 2.259s / 9134 MiB
· 1536²（2.36MP）= 5.086s / 12532 MiB
· 2048²（4.19MP）= 9.598s / 17529 MiB
· 2560²（6.55MP）= 16.611s / 23630 MiB
· 3072²（9.44MP）= 27.555s / 31145 MiB
· 4096²（16.78MP）= 72.948s / 32064 MiB（未 OOM）
显存公式：约 1527 MiB / 兆像素（1024→4096 拟合）；底座 5.5–6.5GB 恒定。
时间随面积线性：1280/1408/1536 三档「时间倍率 ÷ 面积倍率」= 0.949 / 0.955 / 0.984。

画质断点（各档统一下采样到 1024 后取「均值+2σ」亮区做 4-连通标记）：
· 亮区连通域数：21（1024）→ 28（1536）→ 46（2048）→ 94（2560）→ 111（4096）
· 主峰面积占比：2.39%（1024）→ 3.40%（1536）→ 1.63%（2048）→ 0.72%（2560）→ 0.43%（4096）
· 视觉核对：1024/1536 一座灯塔；2048 起出现第二座；3072/4096 变成一排

长宽比对照（同一总面积）：832×1216 = 2.064s / 6766 MiB；1216×832 = 2.075s / 6758 MiB → 差 0.011s / 8 MiB。
双机对照：1024 差 3.51×（5090D 2.259s vs 5060Ti 7.921s）→ 2560 差 4.19×（16.611s vs 69.560s）。
失效边界
本结论为本机实测（RTX 5090D 32GB / 驱动 591.86 / ComfyUI 0.33.0 / sd_xl_base_1.0）。SDXL base 训练分辨率为 1024² 出自 Stability AI 官方模型卡。亮区连通域是相对指标、不等于画质评分；未继续测 4096 以上（已占 98% 显存，边际意义为零）。测试前已停止占卡进程。不同驱动 / 框架版本数值会变。
