pip 缓存空间账：list 命令看不见的那 8 个 G

环境与安装 · 6 步 / 2 分钟L0整理于 2026-10-07 有效期 permanent

pip cache list 只列可复用的 wheel（本机 7 个共 1.4 MB），HTTP 下载缓存完全不进列表——而它才是空间大头（本机 8454.2 MB / 2844 个文件，两者差约 6000 倍）。清空间要看 pip cache info 不看 list，并先认清缓存服务的是哪个解释器（本机两个环境同指一个目录）。

pip缓存磁盘空间Python环境清理

这条适用于

  • 用 pip 装过较多包（下载缓存持续累积）
  • 需要判断哪些空间是「看不见但真实存在」的

版本指纹

pip cache 机制；判据跨版本通用

具体做法

pip cache info 报 8454.2 MB、2844 个 HTTP 文件；pip cache list 只列 7 个 whl 共 1.4 MB。两个最大 body 各 2753196039 / 2753189216 字节，Domain=pytorch.org；按月 08月 4.57 GB / 09月 3.16 GB / 10月 0.15 GB。
失效边界
pip cache purge 会清掉全部下载缓存——下次需要重装这些包时要重新下载；若常有离线安装需求，建议先用 pip download 留存要用的 whl，再 purge。
