ComfyUI 官方模板就绪度怎么核：502 个模板里只有 4 个能直接跑

环境与安装 · 502 模板 / 305 权重 / 1.04 TiB / 61 小时未标注整理于 2026-10-25 有效期 180d

判断「这台机器能不能跑某个 ComfyUI 模板」不要看模板总数，要三查：一查模板是否吃本地权重（api_ 前缀的 231 个发请求到厂商服务器）、二查加载器下拉框里有没有对应文件名（那是 ComfyUI 从磁盘真实扫出来的）、三查单个权重是否超过可用显存。本机 5090D（32607 MiB）实测：502 个模板里 271 个本地模板、224 个要权重、去重 305 个文件，权重全齐的只有 4 个。

这条适用于

  • ComfyUI 0.33.0 服务端可访问（GET /object_info 能返回节点定义），且能拖入官方模板
  • 模板包 comfyui_workflow_templates_json 已装（templates/ 目录下能看到 518 个 JSON）
  • 能读目录与文件体积（扫 D:\models 需要普通读权限即可，不需要管理员）

具体做法

本机实测环境：Windows / ComfyUI 0.33.0 / comfyui-workflow-templates 0.11.43 / RTX 5090 D 32607 MiB / extra_model_paths.yaml 指向 D:\models。

【模板库构成】
· templates/ 目录 518 个 JSON，其中 16 个是 index.*.json 语言索引 → 真模板 502 个
· 502 个里 api_ 前缀 231 个（覆盖 47 家厂商：字节 16 / Seedance 15 / 可灵 14 / Grok 11 / OpenAI 11 / Vidu 11 / Luma 9 / BFL 8 / Recraft 8），本地权重引用 0 个
· 剩下 271 个本地模板：224 个要权重、47 个不要（纯图像处理/参数节点）
· 224 个模板引用的权重去重 305 个文件；其中 124 个带官方直链

【官方直链体积（HF 镜像 X-Linked-Size，124 个全查）】
· 合计 1,142,093,694,166 字节 = 1.039 TiB
· 单文件最大 32.29 GiB（wan2.1_vace_14B_fp16.safetensors）
· 次大 31.86 GiB（hidream_e1_full / hidream_e1_1 bf16）

【本机权重库存】
· 57 个文件条目 / 40 个去重文件名 / 259.46 GiB
· 与 305 个需求交集 16 个
· 权重全齐的模板 4 个：flux_schnell / video_minimax_h3_i2v / video_minimax_h3_t2v / video_wan2_2_5B_ti2v

【下拉可见性（GET /object_info，1116 个节点）】
· 带权重下拉的输入项 45 个（分布 36 个节点）
· 下拉框可见文件名 42 个：其中磁盘真有 22、磁盘没有 20（comfyui_controlnet_aux 硬编码的预处理器名）
· 磁盘有但下拉看不见 18 个 / 76.65 GiB（全是 diffusers 目录结构）
· 空下拉加载器 12 个：ControlNetLoader / DiffControlNetLoader / StyleModelLoader / ModelPatchLoader / SAMLoader / LatentUpscaleModelLoader / FrameInterpolationModelLoader / OpticalFlowLoader / ONNXDetectorProvider / LoadMoGeModel / LoadDA3Model / LoadMediaPipeFaceLandmarker

【缺模型报错原文（POST /prompt 实测）】
type=prompt_outputs_failed_validation → node_errors.1.errors[0].type=value_not_in_list，details 里直接列出「本机能看见的全部文件名」。这是最省事的自检入口。
【下载成本】
· 缺 289 个 / 其中 111 个体积已知 = 977.3 GiB
· 镜像实测 4.56 MB/s（wan_2.1_vae 20s 采样 4.56、umt5_xxl_fp8 4.79）
· 977.3 GiB ÷ 4.56 MB/s = 61.0 小时；70W 下载机电费 4.27 kWh = 2.35 元

【显存分档（按模板最大单个权重）】
· 有体积数据 177 个：≤ 15.93 GiB 141 个（16G 卡装得下）、> 15.93 GiB 36 个、> 31.84 GiB 8 个（5090D 也装不下）
· 36 个装不下的模板涉及 473.1 GiB 权重

失效边界
四点必须说清：① 可跑通判定用的是「权重文件齐备 + 节点类型已注册」两道静态条件，没有逐模板真正跑一遍，运行期 OOM 与显存峰值未验证 ② 权重体积取 HF 响应头声明值，未逐个下载校验，理论上可能与实际文件有差异 ③ 下载速度 4.56 MB/s 是单条镜像线路 20 秒采样，实际受时段与线路影响，波动可能超过一倍 ④ 显存判据用的是「最大单个权重 ≤ 可用显存」这一保守口径，实际还要加 CLIP、VAE、latent 与激活值占用，真实门槛比这个更严——所以 141 个「装得下」的不等于 141 个「跑得动」。
