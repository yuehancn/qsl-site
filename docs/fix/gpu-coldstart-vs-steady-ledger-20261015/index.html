具体做法

本机跑分库实测（2026-10-15 提取，源 = 小程序 seed/benchmarks.json，34 条跑分 / 9 台机器 / 6 组多机对照，经 make_weekly_benchmark.py 提取，未加工）：
同一套 SDXL 工作流（sd_xl_base_1.0 / steps 20 / CFG 7.0 / euler + normal / batch 1 / ComfyUI 0.33.0）：
· 单张 1024×1024：5090D 4.98 秒 vs 5060Ti 16.68 秒 = 3.35×
· 批量 4 张 1024²：5090D 16.69 秒/批 vs 5060Ti 64.99 秒/批 = 3.89×
· 单张 768×1344 竖屏：5090D 5.09 秒 vs 5060Ti 16.54 秒 = 3.25×
· 冷启动（含模型加载）：5090D 5.03 秒 vs 5060Ti 25.72 秒 = 5.11×

冷启动相对稳态的额外开销：5090D 只多 0.05 秒；5060Ti 多 9.04 秒（模型权重 6.94GB 需按需搬运）。

显存峰值：
· 单张：5090D 15301 MB vs 5060Ti 12471 MB = 1.23×
· 批量 4 张：5090D 23507 MB vs 5060Ti 15922 MB = 1.48×（5060Ti 官方 16311 MiB，仅剩 389 MiB）

倍数随分辨率放大：1024² 差 3.51× → 2560² 差 4.19×（5090D 16.611 秒 vs 5060Ti 69.560 秒）。

同榜其他组：
· DGX Spark 集群（DeepSeek-V4.1-Flash）：TTFT 151 ms / 单请求 decode 42.51 tok/s / 长上下文 prefill 2311 tok/s / 并发 8 吞吐 148.95 tok/s（加速比 3.62×）/ 并发 16 吞吐 148.22 tok/s（比并发 8 低 0.5%，单请求等待 20.24 秒）
· 成片响度：未归一化 −24.25 LUFS → 两遍 loudnorm 后 −14.93 LUFS（47 条）
· 数字人 S2V 单段 8 秒画面 186 秒/段
· Blender 单进程批量导 8 个资产 0.430 秒/批
· SDXL 单张 1 步采样 0.448 秒（固定开销，占 84.3%）/ 每步边际 83.49 ms

失效边界
本结论为本机实测（RTX 5090D 32GB + RTX 5060 Ti 16GB / ComfyUI 0.33.0 / sd_xl_base_1.0；驱动 591.86）。所有时间取 3 次重复的中位数，显存为 0.1–0.15 秒采样峰值。跑分表数值来自本机跑分库，除四舍五入外未做任何加工。测量前已停止占卡进程。冷启动额外开销为「含模型加载」与「稳态」两档之差。因硬件、驱动与框架版本差异，你的数值可能与本文不同。
