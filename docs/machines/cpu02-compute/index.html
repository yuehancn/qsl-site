2026-11-06 实测：2×20C/80T 双 NUMA / 125 GiB / Ubuntu 26.04.1。无独立显卡（nvidia-smi 不可用，正常）。🔴 这是纯 CPU 推理的主力测试机：2026-11-06 在它上面测出 llama.cpp 跑 PLaMo 0.8B Q4_K_M 的 decode 曲线（1/2/4/8/16/20 线程 = 14.68/24.42/36.56/40.64/42.04/41.72 tok/s，8 线程饱和），prefill 同期从 49.43 涨到 701.39 t/s —— decode 吃内存带宽、prefill 吃算力，同一台机器两个最优线程数。⚠️ 双路机器必须先用 taskset 或 numactl 绑单 NUMA 再测线程，否则线程跨节点访问远程内存，测出来的数每次都不一样。⚠️ 纯 CPU 机，不参与显存类跑分对照。
